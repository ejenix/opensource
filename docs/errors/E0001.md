# E0001 — Source could not be resolved

The compiler asked the analyzer for a resolved compilation unit and did not get
one. This is not a normal syntax error (those are reported as
[E0000](E0000.md)); it means the file could not be read or resolved into a unit
at all.

## Why

Before lowering, the compiler resolves the input through an analysis context. If
the analyzer returns anything other than a resolved unit — for example the path
does not point at a readable Dart file, or the analysis session was torn down —
there is nothing to compile.

## Common causes

- The input path does not exist or is not readable.
- The file is empty or is not a Dart source file.
- The file lives outside any analyzable root (a misconfigured include path).

## How to fix

Confirm the path passed to `ejenix build` points at a real, readable `.dart`
file, and that the file contains Dart source. `ejenix doctor` checks that your
environment can resolve and compile a trivial program end-to-end.
