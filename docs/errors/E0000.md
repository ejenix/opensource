# E0000 — Analyzer error

The source does not analyze cleanly: it has a syntax or resolution error that
the Dart analyzer reports. The Ejenix compiler surfaces the analyzer's own message and
stops before lowering, so a broken program is never partially compiled. No
Ejenix bundle is produced.

## Why

Compilation is built on `package:analyzer`. Any error-severity diagnostic from
the frontend (a missing semicolon, an undefined name, a type error) makes the
program ill-formed, and lowering ill-formed code would produce meaningless
bytecode. The original analyzer message is preserved verbatim so it matches what
your IDE shows.

## Example

```dart
int f() { return ; }   // Expected an expression after 'return'
```

```
input.dart:1:18: error [E0000]: Expected an expression.
```

## How to fix

Fix the underlying Dart error the message describes — exactly as you would in
your editor. Run `dart analyze` on the file to see the full context. Once the
source analyzes cleanly, recompile.
